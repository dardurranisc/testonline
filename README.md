# Test Online — приложение для создания и прохождения тестов

Учебный проект по React/Redux. Приложение для создания и прохождения тестов  
с двумя ролями пользователей: администратор и пользователь. Поддерживает три типа  
вопросов, модальные окна, кастомные элементы форм, drag and drop и расчёт результата.

## Демо
- https://testonline-ebon.vercel.app/
- https://github.com/dardurranisc/testonline

## Стек
- React
- Redux
- Redux Saga
- React Router
- Внешний API
- SCSS / CSS Modules
- JavaScript (ES6+)

## Требования к заданию
- Приложение для создания и прохождения тестов
- Две роли: администратор (CRUD тестов и вопросов + прохождение) и пользователь (только прохождение)
- Три типа вопросов: «один из списка», «несколько из списка», «численный ответ»
- Адаптивность на всех разрешениях, поддержка Firefox, Chrome, Safari
- Кастомные DOM-элементы форм и dropdown
- REST API: GET, POST, PUT, DELETE
- Redux Saga для сайд-эффектов

## Роли пользователей
- **Администратор** — создаёт, редактирует, удаляет тесты и вопросы, проходит тесты
- **Пользователь** — проходит тесты

## Экраны и функционал

### Экран входа
- Форма ввода логина и пароля
- Проверка валидности данных
- Перенаправление на главный экран или вывод ошибки

### Модальное окно (общий компонент)
- Заголовок и контентная область
- Затемнение фона
- Закрытие: клик по фону, крестик, ESC, кнопка «Отмена»
- Центрирование на экране
- Блокировка скролла страницы при открытом окне

### Экран создания/редактирования/удаления теста
- Поле для ввода названия теста
- Кнопка «Сохранить»
- Список созданных вопросов с кнопками редактирования и удаления (крестик)
- Кнопка добавления вопроса
- Dropdown для выбора типа вопроса
- Кнопка «Удалить» для удаления теста
- Модальное окно подтверждения при сохранении/удалении
- Сохранение даты создания теста для сортировки

### Формы вопросов

**Один из списка**
- Инпуты для вопроса и вариантов ответа
- Динамическое расширение формы
- Checkbox для указания правильного варианта
- Drag and drop вариантов, сохранение порядка
- Валидация: минимум 2 варианта, ровно 1 правильный

**Несколько из списка**
- Инпуты для вопроса и вариантов ответа
- Динамическое расширение формы
- Checkbox для указания правильных вариантов
- Drag and drop вариантов, сохранение порядка
- Валидация: минимум 2 варианта, хотя бы 1 правильный

**Численный ответ**
- Инпут для вопроса и поле для правильного численного ответа
- Валидация: поле численного ответа не пустое

### Главный экран (список тестов)
- Список созданных тестов
- Поле фильтрации по названию
- Ссылка на экран входа
- Ссылка на экран добавления теста
- Сортировка по дате создания с переключением порядка
- Для администратора — кнопка перехода на экран редактирования
- При клике на тест — модальное окно «Начать прохождение теста?» с кнопками «Подтвердить» и «Отмена»
- Пагинация списка (порционная подгрузка)

### Экран прохождения теста
- Отображение вопросов в зависимости от типа
- **Один из списка:** текст вопроса + radio buttons
- **Несколько из списка:** текст вопроса + checkbox
- **Численный ответ:** текст вопроса + number input
- Кнопка «Закончить прохождение теста»
- Расчёт результата (количество правильных ответов)
- Модальное окно с результатом и кнопкой «Вернуться к списку тестов»

## Архитектура
- **Store** — единое хранилище Redux
- **Redux Saga** — обработка асинхронных запросов и сайд-эффектов
- **React Router** — маршрутизация между экранами
- **JSON Server** — REST API для хранения тестов и вопросов
- **Компоненты:**
  - `commons/` — переиспользуемые (Modal, Button, Input, Checkbox, Radio, Dropdown)
  - `pages/` — экраны приложения (Login, TestsList, TestEdit, TestPass)
